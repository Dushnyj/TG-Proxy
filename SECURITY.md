# Security Policy

## Поддерживаемые Версии

TG Proxy находится в ранней разработке. Исправления безопасности выпускаются для последней опубликованной версии.

| Версия | Поддержка |
| --- | --- |
| latest | Да |
| older | Только критические исправления по возможности |

## Как Сообщить Об Уязвимости

Не публикуйте рабочие эксплойты, приватные ключи, токены, proxy secrets или персональные данные в публичных issues.

Сообщение должно содержать:

- версию TG Proxy;
- модель Android и версию системы;
- краткое описание проблемы;
- шаги воспроизведения;
- ожидаемое и фактическое поведение;
- логи без секретов и персональных данных.

Если проблема связана с GitHub Releases, APK-подписью или обновлением приложения, приложите имя APK и SHA256 из `SHA256SUMS.txt`.

## Секреты

Не отправляйте:

- Android keystore;
- пароли подписи;
- GitHub tokens;
- MTProto secret, если он используется на вашем устройстве;
- приватные Cloudflare Worker домены, если они не предназначены для публикации.

## Область Проекта

TG Proxy реализует локальный MTProto-прокси для Telegram и настройки маршрутизации. Проблемы сторонних клиентов Telegram, прошивок Android, сетей операторов и Cloudflare-инфраструктуры рассматриваются только если они воспроизводимо связаны с кодом TG Proxy.
